Nave — Pago por redirección para Odoo

Tarjetas, MODO y QR integrados en tu eCommerce

Integrá Nave como método de pago en tu tienda Odoo. Tus clientes son redirigidos al checkout de Nave para pagar con tarjetas de crédito/débito, MODO o QR, y vuelven automáticamente a tu sitio al finalizar.

Características

Para el comercio

  • Configuración simple: Client ID, Client Secret y POS ID
  • Entorno sandbox para pruebas
  • Webhook server-to-server para actualización automática de estados
  • Cron de polling como safety net
  • Número de operación visible en las transacciones

Técnico

  • Compatible con Odoo 16, 17 y 18
  • Community y Enterprise
  • Sin dependencias externas más allá de requests
  • Token de acceso cacheado automáticamente
  • Seguridad: tokens de un solo uso, HMAC timing-safe

Configuración

  1. Instalá el módulo desde Aplicaciones → Nave Payment Provider
  2. Ir a Contabilidad → Configuración → Proveedores de pago
  3. Buscá Nave y completá Client ID, Client Secret y POS ID
  4. Cambiá el estado a Habilitado
  5. ¡Listo! Nave aparecerá en el checkout de tu tienda
